Chess Analytics

Python Stockfish Tableau API

An end-to-end pipeline that fetches my complete game history from the Chess.com API, runs Stockfish engine analysis on recent games to detect blunders and classify moves, and feeds a two-dashboard Tableau workbook covering overall performance and per-move analysis.

Approach

  • Chess.com API integration with local caching at every stage
  • PGN parsing to extract moves, openings, ELO and result data
  • Stockfish analysis via chess.engine — best move eval vs actual move eval
  • Win percentage loss used to classify moves and detect blunders
  • Two Tableau dashboards: overall stats and last-20-games analysis

Key findings

  • Blitz ELO up from ~1,000 in 2019 to ~1,349 in 2026
  • 3.23% blunder rate across 20 analysed games
  • 34.92% best move rate — consistent with 1,200–1,400 ELO range
  • Center Game best opening at 53.5% win rate across 572 games
  • 23,700+ games in dataset, almost exclusively blitz

Airbnb NYC Revenue Analysis

Python SQL Statistical analysis

What separates top-performing Airbnb listings in New York from the rest? I compared the top 1% of listings against the full dataset to identify which factors actually drive revenue — and which common assumptions don't hold up.

Approach

  • Automated data cleaning pipeline with outlier detection
  • SQLite database for complex querying across listing attributes
  • Comparative analysis framework: top 1% vs full dataset
  • Side-by-side visualisations to surface patterns clearly

Key findings

  • Bronx and Queens outperform Manhattan on revenue potential
  • 3–4 star ratings outperform 5 stars — diminishing returns above that
  • 1–2 night minimum stay is the optimal configuration
  • Instant booking and portfolio size have minimal effect

E-Commerce Commercial Performance Analysis

Python Time-series Marketing attribution

Analysis of 20,000+ completed orders totalling $3.76M to evaluate revenue trends, commercial performance, and marketing channel effectiveness — including surfacing data quality issues that would otherwise mislead business decisions.

Approach

  • Data cleaning with deduplication, null handling, IQR outlier removal
  • KPI calculation across revenue, order volume, and customer behaviour
  • Time-series aggregation at daily and monthly granularity
  • Marketing channel performance by volume and average order value

Key findings

  • Revenue growth is event-driven, not consistent month-to-month
  • Direct traffic dominates volume — strong brand-led demand
  • Affiliate channel delivers highest average order value despite lower volume
  • Incomplete attribution limits full marketing visibility
